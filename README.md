# QUORUM

Every token deserves a council.

Static site: `index.html` and `logo.png`, no build step.

## Deploy on Vercel
1. Push these files to the root of a GitHub repo.
2. In Vercel, import the repo. Framework preset: **Other**. Leave build command and output directory empty.
3. Deploy.

## Before launch
At the top of the script in `index.html`, fill in `CONFIG`:
`ca` (contract address), `buy` (buy link) and `chart` (chart link). The X link is already set to https://x.com/QuorumAIFun.
